# Briefing for the 2026-10-10 review agents

## The repo
/home/alex/Code/recomp is a readable-C port ("recomp") of the GBA game Mega Man Battle Network 6 Falzar.
- bn6f/ : the disassembly (git submodule; fixes go on its recomp-fixes branch and the built ROM must stay
  byte-identical). Symbol names/comments the project discovers are written back here.
- tools/lifter/lift.py : translates every function of the original ARM/Thumb code into exact but unreadable C
  (cport/src/lifted, generated). The game runs entirely on this.
- cport/ : the port. cport/src/game/*.c hold the readable functions (`Next NAME(void)` bodies override the
  lifted ones): about 1,435, almost all still in "register form" (guest registers R0..R12, flags, GUEST_CALL)
  rather than typed C.
- tools/convert/farm.py : cheap outside LLMs convert small functions one at a time; results in
  tools/convert/accepted/ (untracked), per-round logs in tools/convert/log/, token usage in
  tools/convert/usage.jsonl, pass rates via tools/convert/scorecard.py.
- tools/llm.py : every model call (providers from ~/.pi/agent/models.json; NEVER print ~/.pi/agent/auth.json).
- tools/wf/ : Burr workflow graphs (typed pydantic) running the pipeline: capture (real inputs per function from
  replayed gameplay routes), farm, convert (whole files via strong models; tools/wf/wf/tools/subsystem.py has its
  rules), drafts (models draft symbols/db entries), verify (host difftest vs lifted, CPU oracle, lockstep vs the
  original ROM on 13 routes in tools/traces), record (names/comments into bn6f and symbols/db). Model routing:
  tools/wf/wf/tools/sources.py and models.py. Map: docs/orchestration.html; rationale: docs/PROCESS.md.
- tools/abi/ : lint.py (register-level code; baseline lint_baseline.json), gen.py, gen_structs.py, call_edges.py,
  report.py, captures.py. Target convention: docs/C_CALLING_CONVENTION.md = typed C + thin `Next` adapters,
  `/* register form: why */` notes where C can't work.
- symbols/db/ : one record per discovered symbol with evidence and reproduction steps.
